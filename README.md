# Календарь дней

Приложение-календарь месячного цикла, сделанное прежде всего для незрячих.
Всё, что приложение знает, оно говорит словами: ни одного вывода, который
существует только цветом, ни одной картинки, без которой что-то непонятно.

Для всех девушек: то, что удобно без зрения, удобно и всем остальным. Ни
рекламы, ни аналитики, ни интернета — приложению не нужно никуда подключаться,
чтобы работать, и записи никуда не уходят.

## Из чего состоит

```
core/cycle_core/     ядро: вся логика, ни строки ввода-вывода
core/tests/          проверки ядра (100+)
android/             оболочка для Android: Kotlin + Chaquopy
desktop/             оболочка для Windows: PySide6
tools/               рисование значков (один рисунок на обе платформы)
```

**Ядро одно, оболочек две.** Расчёт цикла, прогноз, тексты для скринридера,
дневник, напоминания живут в `core/cycle_core` и покрыты тестами. Оболочки
только показывают то, что ядро посчитало. Мост между ними —
`cycle_core/engine.py`: строки и JSON на входе и выходе. Один и тот же код
работает и на телефоне, и на компьютере.

## Экраны

**Телефон.** «Сегодня» — первое, что слышно при открытии; отметки «начались» и
«закончились»; календарь месяца списком, где каждая строка — целый день,
прочитанный словами; дневник самочувствия (боль, настроение, выделения,
температура, таблетка, заметка, итоги и список записей); напоминания и
настройки — за сколько дней предупреждать, тихие часы, «что напомнит дальше».

**Компьютер.** Те же экраны плюс резервная копия одним файлом и правка отметок
задним числом. Закрытое окно программу не выключает: она остаётся в трее рядом
с часами и продолжает напоминать, а напоминание само поднимает окно. В
настройках есть галочка «запускать вместе с Windows», чтобы первое же
напоминание не ждало, пока программу откроют руками.

**Напоминания на телефоне молчат о личном.** Уведомление говорит только
«Есть напоминание — открой приложение»: экран блокировки видят и другие. Что
именно напомнить, приложение говорит голосом внутри себя, и только один раз.

## Модули ядра

- `models.py` — типы: период, запись дневника, сводка по истории.
- `stats.py` — длины циклов, средние, разброс, признак нерегулярности.
- `predict.py` — день цикла, фазы, овуляция, фертильное окно, задержка.
- `phrases.py` — все тексты, которые слышит пользовательница.
- `journal.py` — отметки начала и конца, чтение и запись истории.
- `diary.py` — дневник самочувствия и выжимка из него.
- `reminders.py` — что и когда напомнить, включая тихие часы.
- `engine.py` — строковый интерфейс для оболочек.

## Проверки

```
python3 -m unittest discover -s core/tests          # ядро, 100+ проверок
QT_QPA_PLATFORM=offscreen python3 desktop/smoke_test.py   # окно Windows
```

Проверок много намеренно: у приложения незрячая пользовательница, которая не
увидит, что «что-то поехало». Ошибку должен ловить тест, а не она.

## Сборка

- **Android:** `.github/workflows/build-android.yml`, APK в артефактах.
- **Windows:** `.github/workflows/build-windows.yml`, готовая папка в архиве;
  можно собрать и самому — `desktop/build-windows.bat`.

## Чего приложение не делает

Не защищает от беременности, не назначает лечение, не даёт медицинских
советов. Прогноз всегда остаётся прогнозом: при нерегулярном цикле приложение
говорит об этом прямо и называет диапазон дат вместо одной «точной».
