# «Календарь дней» для Windows

Сделан для незрячих: всё, что приложение знает, оно говорит словами, и ни одно
действие не спрятано в картинку. Работает с NVDA и JAWS — это обычные окна
Windows, диктор читает их сам.

## Как запустить

**Готовой сборкой.** Распакуйте папку `KalendarDney` целиком (не по частям —
рядом с `KalendarDney.exe` лежат нужные файлы) и запустите `KalendarDney.exe`.
Ярлык можно вынести на рабочий стол или в меню «Пуск».

**Из исходников.** Нужен Python 3.10+:

```
pip install --user -r requirements.txt
python main.py
```

**Собрать самому.** Запустите `build-windows.bat` — он поставит библиотеки,
прогонит проверки и соберёт папку `dist\KalendarDney`.

## Что оно умеет

**Сегодня.** Открывается и сразу говорит: какое сегодня число, какой день
цикла, какая фаза, когда ждать следующие месячные и овуляцию. Две кнопки —
«Отметить первый день месячных» и «Отметить последний день». Вторую нужно
нажимать только в последний день; пока месячные идут, она выключена.

**Календарь.** Месяц списком: каждая строка — день словами, например
«12 марта: 15-й день цикла, овуляция, фертильный день». Стрелками вверх-вниз
листаются дни, диктор читает строку целиком. Кнопка «Отметить начало месячных
в выбранный день» ставит отметку задним числом, «Убрать отметку» — убирает
ошибочную.

**Дневник.** Боль по шкале от 1 до 5, настроение, выделения, базальная
температура, таблетка, заметка. Заполнять не обязательно — можно отмечать
только то, что хочется. Кнопка «Что видно по дневнику» говорит словами, что
заметно за всё время: средняя боль, на какие дни цикла она чаще приходится,
был ли подъём температуры.

**История.** Циклы списком: длина каждого, длительность месячных — то, что
показывают врачу.

**Напоминания.** Предупреждение за пару дней до месячных, напоминание в
ожидаемый день, сообщение при задержке, начало фертильных дней, напоминание
про таблетку. Настраиваются порознь, есть тихие часы.

**Резервная копия.** Всё в одном файле: «Сохранить резервную копию» и
«Восстановить из копии» в настройках. Перенос на другой компьютер — этим
файлом.

## Что важно помнить

Закрытое окно программу не выключает: она прячется в трей, к значку рядом с
часами, и продолжает напоминать. Когда придёт напоминание, окно поднимется
само. Открыть программу заново — двойной щелчок по значку в трее или «Открыть
окно» в его меню (меню вызывается правой кнопкой мыши или клавишей
«Контекстное меню» на значке). Выйти совсем — «Выход» в том же меню.

В настройках, в разделе «Работа программы», две галочки. «Продолжать работу,
когда окно закрыто» — включена по умолчанию; снимите её, если хотите, чтобы
крестик закрывал программу целиком. «Запускать вместе с Windows» — чтобы
напоминания работали с самого включения компьютера, без открытия окна руками.

Оно не защищает от беременности и не заменяет врача. Прогноз — всегда прогноз:
если цикл нерегулярный, приложение честно об этом говорит и показывает
диапазон дат, а не одну «точную».

## Где лежат данные

В папке `%APPDATA%\Календарь дней` — пять файлов: история, дневник, настройки
напоминаний, список уже показанных напоминаний и настройки самой программы
(продолжать ли работу с закрытым окном, автозапуск). Кнопка «Открыть папку с
данными» в настройках открывает её.

## Как это проверяется

- `core/tests` — 100+ проверок ядра: расчёт цикла, прогноз, тексты для
  диктора, дневник, напоминания. Запуск: `python3 -m unittest discover -s core/tests`
  из корня проекта.
- `desktop/smoke_test.py` — проверка окна: собирается, кнопки работают,
  отметки сохраняются, копия восстанавливается, напоминание всплывает один
  раз. Запускается без экрана (`QT_QPA_PLATFORM=offscreen`), поэтому годится
  и для сборки на сервере.
